auroraADE

Aesthetic Desktop Environment

auroraADE is the desktop environment direction within reachOS. Its target architecture is x86_64.

reachOS is the wider operating-system project. Fabric Dessert is the virtual hardware platform and board architecture described in the reachOS source.

Project responsibilities

Project Responsibility
reachOS The wider operating-system project.
Fabric Dessert The virtual hardware platform and board architecture in the reachOS repository.
auroraADE The desktop environment direction, targeting x86_64.
