DECEMBER REACH / DESKTOP ENVIRONMENT

auroraADE

Aesthetic Desktop Environment

auroraADE is the desktop environment direction within reachOS. Its target architecture is x86_64. It describes the desktop layer of the project, rather than the virtual hardware platform beneath it.

Project structure

These names describe separate responsibilities within the wider project.

Name Role Scope
reachOS Operating-system project The wider project these components belong to.
Fabric Dessert Virtual hardware platform Board and platform infrastructure documented in the reachOS source.
auroraADE Desktop environment direction The desktop-facing environment, targeting x86_64.
