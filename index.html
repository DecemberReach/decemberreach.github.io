The idea

A desktop environment, within a bigger system.

reachOS is the operating-system project. auroraADE is its desktop environment direction: a separate layer focused on the desktop experience, not a different name for the whole OS.

01 / DESKTOP

Made for the desktop

auroraADE is the desktop-focused environment within the reachOS ecosystem, with the desktop experience as its centre of attention.

02 / ARCHITECTURE

An x86_64 direction

The project direction for auroraADE is x86_64-based, keeping its intended desktop target distinct from reachOS as a whole.

03 / IDENTITY

Aesthetic by design

The name says what it is about: an aesthetic desktop environment with its own identity, within the wider reachOS project.

The reachOS connection

One project. Distinct layers.

auroraADE is not presented as a standalone operating system. It belongs to reachOS, while keeping a focused role as the desktop environment.

The visual language here takes inspiration from Ubuntu’s clear, confident web presentation. The site itself uses Canonical’s Vanilla Framework, rather than merely imitating its appearance.
