REACHOS / DESKTOP ENVIRONMENT

auroraADE

A desktop environment for reachOS.

auroraADE is the desktop layer of reachOS: a distinct visual environment designed around the experience of using a desktop.

ADE stands for Aesthetic Desktop Environment.

Discover auroraADE Explore reachOS ↗

The desktop is one layer of the system.

The desktop is where the wider system becomes a daily environment.

auroraADE focuses on that layer — the workspace, windows and visual language that shape the desktop experience. It belongs to reachOS rather than replacing the name of the operating-system project.

The direction behind auroraADE

These principles describe the project's direction, not a claim that every part is already implemented.

Desktop, first

A focused environment for the desktop experience, rather than a label for the whole operating system.

x86_64 direction

auroraADE's stated architecture direction is x86_64.

A distinct identity

ADE means Aesthetic Desktop Environment — a name tied to the visual role of the project.

Part of reachOS

The desktop environment is presented in context, as one part of the wider reachOS project.

One project. Distinct roles.

reachOS is the operating-system project. auroraADE is the desktop environment direction within it — a distinct experience with a clear place in the wider system.
